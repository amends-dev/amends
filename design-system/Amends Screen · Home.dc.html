Decided on this screen
01An empty bucket keeps its heading and gets a short drawing inline. Only an empty screen earns the full centred treatment — otherwise every quiet morning looks like a broken app.
02The greeting carries the count, so the headline is the only place that says how much is waiting. Buckets below just organise it.
03Offline says the runs continue on the server. A stale view that looks empty is worse than an error, because you would go and start the work again.
04Three drawings added here: first run as an empty hoop, nothing running as a parked needle, disconnected as a needle with an empty eye. One still owed — no results, which belongs to a search screen we do not have yet.
