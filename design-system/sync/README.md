# Token sync — historical Foundations v2 handoff

The four files here are design-reference artifacts from an earlier UI structure.
They are not imported by the application. The UI implementations they describe were removed;
the current `apps/ui` package is built from the Lunacy mocks in
`Amends Group Exploration.free`. The handoff's source paths and contract names remain
historical.

Use the [UI guide](../../apps/ui/README.md) for current foundations, components, themes, and
validation. Its [color tokens](../../apps/ui/src/foundations/color/tokens.ts) and
[theme variables](../../apps/ui/src/foundations/theme/vars.css.ts) own the current color
contract; these artifacts are not replacement source files or a current token map.

The handoff proposed warm neutrals, a persimmon accent, flat page surfaces,
ink-colored focus and controls, and a 7px/6px decorative stitch. Its references to
`night`, `elevation.raised`, and `elevation.lifted` are not current repair instructions.
