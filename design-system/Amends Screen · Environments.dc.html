No environments An agent cannot run without one — there would be no program to start and nowhere to start it. Every agent points at exactly one.
Decided on this screen
01The harness is a value here, not a record elsewhere. It is a kind plus an optional command override — the binary itself lives in the base image, so the two are already coupled. Same place, two programs, means two environments.
02There is no "no sandbox" option. Every session runs somewhere; a host that wants this machine registers a local-process provider instead. Nowhere is not a place.
03The model list is derived, never declared. A binary has no fixed model list; what is fixed per kind is the protocols it can be pointed at. Catalog providers that speak one of them, and their models, are what an agent here can choose.
04Amends checks the harness is present; it never installs it. The install line sits beside the picker and in the failure, so the cost of a bare base is visible and the fix is one copyable line.
05A model reachable through two providers is one model with two doors. The route is the workspace's business, ordered by when each connection was opened, so the list shows which door is in use rather than asking you to choose one.
