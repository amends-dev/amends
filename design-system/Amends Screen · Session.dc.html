Decided on this screen
01Chronological, oldest first, with follow-latest on by default. New rows append at the bottom and the view keeps pace; scroll up and following stops, replaced by a pill that counts what you have not seen. Nothing ever moves under the reader.
02A failed tool is a coloured outcome on one row, not a failed session. The reconcile command fails, the agent reads the failure, fixes the rule and carries on — all inside the same execution.
03The asked a question state is the important one: the session finished normally, and its own record says so, while the attempt is paused and the task is held. All three are shown in the aside so they can disagree in public.
04Cost and usage are shown only when recorded. A failed model exchange says unavailable rather than $0.00 — an unknown price is not a free one.
05A routing consultation gets the same screen with no numbered attempt. It has a harness, a sandbox and a log like any session — what it lacks is a task, because it produced a decision rather than work. It is the case that proves a session is not always a task attempt.
