Decided on this screen
01The tier picker never states a tier in the abstract. Choosing one rewrites the permission list underneath it, so you read what the agent may do rather than what the level is called.
02There is no own tier here, because an agent cannot hold it. Only a person can be the one who answers for the workspace.
03Concurrency is drawn as slots, filled by what is running right now. Lowering it below what is in flight is allowed and says plainly that current work finishes first.
04The environment is picked first and is required, because its harness decides which models exist at all. An empty model is meaningful only when that harness is managed and brings its own; anywhere else it is a missing setting that stops the agent running.
05Removal is retention, not deletion. The row stays so every turn it recorded still has an author; it simply stops being assignable.
