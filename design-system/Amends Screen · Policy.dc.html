Decided on this screen
01The rule sentence is generated from the conditions, never typed. It cannot drift from what will actually be evaluated, which is the whole reason the trace on Triage can be trusted.
02Reordering is a change, not a preference — so a move shows in the publish summary in the same language as an edit. Order is the only thing that decides which of two matching rules wins.
03A past version is read-only and carries the decisions it made. That is the point of keeping them: you can ask why something was routed in August and get the August answer.
04Two marks to add to the glyph table, which is at 26: ≡ for policy, an ordered set of lines, and ✎ for edit. Neither collides with an existing mark — / keeps command.
05Open question: reverting. Right now the only honest revert is publishing a new version whose rules match an old one — there is no way to un-publish. Say if you want a one-click "restore version 6" that does exactly that.
