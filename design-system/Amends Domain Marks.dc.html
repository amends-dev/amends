Domain marks

Seven small components that carry a noun from the model. They are the vocabulary everything else is written in, so each one is shown doing its actual job rather than sitting in a swatch — advance a task through its life, put an agent at its concurrency limit, push a due date past its date.

01

PrincipalRef

four kinds · three sizes

Anyone who can act. The four kinds have to be told apart at a glance everywhere, and colour is not available for it — so the shape of the mark does the work: a person is a filled circle, an agent is a dashed ring, an outside contact is a square, and the system is the brand mark on ink.

{{ p.initial }} {{ p.name }} {{ p.kind }}
Rules Inline drops the kind label and rides the text baseline. Chip is the list and header size. Row is the only one that may carry presence. A principal never changes shape between sizes — an agent is a dashed ring at 16px and at 40px.

03

Presence

not a green dot

An agent is available, working at some number of its concurrency limit, or offline. "Busy" is a quantity, not a state, so the mark counts: one stitch per running session against the limit.

a Ada {{ presLabel }}
running {{ running }} · limit {{ limit }}
At the limit the ring goes solid ink: the agent will not pick anything else up. Offline drops the mark to line.seam and the name to tertiary — the only place presence is allowed to change the name's colour.
04

Mention

hover one

Mentioning someone does not assign them anything, so a mention must not borrow the assignment treatment. A mention is the name with a hairline underline; an assignment is a principal with a verb attached to it.

Mention · in a message

Pulling in @AdaaAdaagentMentioned here. Not assigned anything. because she wrote the retry policy, and @JoJMJo MerceruserMentioned here. Not assigned anything. signed off the last one.

Assignment · for contrast
assigned to a Ada
The assignment sits in a filled pill with a verb in front of it and lives in the task header, never in prose. If it appears in a sentence, it is a mention.
05

DueDate

push it past the date
{{ dueLabel }} {{ dueAbsolute }}
a day at a time
Overdue is the one place in a task row that danger is allowed. Today is pending. Everything further out is plain tertiary ink with no dot at all — a due date three weeks away is not news.
