# Workspace mark

A noninteractive workspace identity mark for lists and sidebar headers. Supply initials
as children and either `decorative` beside a visible name or a full `aria-label`.
Empty initials use `?`. Theme, identity, and navigation belong to the caller.

`variant="brand"` selects the Shell reference's persimmon surface and light text
through the workspace-mark color roles. The pair is shared by both themes and has
tested 4.78:1 contrast. `neutral` remains the default. Brand and the matching color
foundation story cover the new treatment.

The picker reference uses a 38px square serif mark. This version scales with root
text, uses the reviewed medium radius and neutral panel/text/control tokens, and
does not infer a selected workspace or brand color. Comparison covers both themes;
Enlarged covers RTL and magnification.
