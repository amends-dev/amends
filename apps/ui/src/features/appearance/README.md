# Theme choice

Controlled native radios for light (Cotton), dark (Soot), and system preference.
Pass `value` and `onValueChange`; the component owns no storage, system listener,
or ThemeProvider. Each instance has its own native radio group. Preview colors
use the actual palettes; checked and focus states remain visible independently.

The Shell v2 reference supplies the three preview cards. Native radio behavior
provides Tab, arrow keys, and Space. Text and cards wrap at narrow/enlarged sizes.
Comparison, Narrow, Enlarged RTL, and Interaction cover both themes, disabled
controls, selection, and element preservation.
